# Makita LXT accu-clip (release button v2) met RH-logo

Dit is de clip die daadwerkelijk in Franks accu zit — losgeschroefd en opgemeten.
Basis: STEP-bestand van MakerWorld model 3026022, aangeleverd door Frank.
De eerdere modellen in de bovenliggende map horen bij een ander (niet-passend) type knop.

Afmetingen: 45,9 x 36,9 x 29,0 mm. Duimkommetje: vlakke vloer 25,8 x 10,9 mm,
2,7 mm diep. Logo staat 22 mm breed en 0,8 mm verhoogd op die vloer, dus ruim
onder de rand.

## Bestanden

| Bestand | Wat |
| --- | --- |
| `lxt_clip_RH_oranje_wit.3mf` | Kant-en-klaar voor Bambu Studio: oranje clip, wit RH-logo (AMS) |
| `lxt_RH_compleet.stl` | Eén kleur, logo verhoogd |
| `lxt_button.stl` + `lxt_RH_logo.stl` | De twee delen los |
| `lxt_clip_logo.scad` | Parametrisch: logo/initialen, grootte en hoogte aanpasbaar |
| `lxt_release_button_v2.STEP` | Het originele CAD-bronbestand |

## Printen

- PETG (of PA-CF / PETG-CF, dichter bij het originele PA6-GF30 glasnylon)
- 6 wanden of hoge infill, laaghoogte 0,12-0,16 mm
- Veertje van de oude clip hergebruiken
