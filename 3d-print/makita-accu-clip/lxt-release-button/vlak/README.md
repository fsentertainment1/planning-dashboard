# Vlak ingelegd merk (aanbevolen)

Het merk ligt hier gelijk met de bodem van het duimkommetje: geen reliëf.
Makkelijker printen (geen overhangende randjes), strakker resultaat en het
kan niet afslijten.

Het merk is 0,6 mm diep verzonken. De wand onder het kommetje is 1,22 mm,
dus er blijft ruim 0,6 mm materiaal over. Bij 0,12 mm laaghoogte zijn dat
5 lagen wit - ruim voldoende voor dekkende kleur.

| Bestand | Wat |
| --- | --- |
| `clip_RH_vlak.3mf` | RH-logo, clip op filament 1, logo op filament 2 |
| `clip_FSlogo_vlak.3mf` | FS-beeldmerk, idem |
| `clip_FStekst_vlak.3mf` | FS-letters, idem |
| `vlak_<merk>_romp.stl` + `vlak_<merk>_merk.stl` | dezelfde delen los |
| `lxt_clip_vlak.scad` | parametrisch: merk, maat en diepte aanpasbaar |

Romp + merk samen = exact het volume van de originele clip, dus de delen
sluiten naadloos aan.
