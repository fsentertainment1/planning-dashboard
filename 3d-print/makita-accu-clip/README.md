# Makita 18V accu-clip (vergrendelknop) met initialen

Vervangende vergrendelclip voor een Makita 18V LXT accu (o.a. BL1850B):
accubehuizing losschroeven, kapotte clip + veertje eruit, veertje hergebruiken
met deze print.

## Bestanden

| Bestand | Wat |
| --- | --- |
| `makita_clip_FS_oranje_wit.3mf` | Kant-en-klaar voor Bambu Studio: oranje clip, witte FS-letters (AMS, 2 kleuren) |
| `makita_clip_FS_romp.stl` + `makita_clip_FS_letters.stl` | Zelfde twee delen als losse STL's (samen laden als één object) |
| `makita_clip_FS.stl` | Eén kleur, verhoogde letters |
| `makita_clip_FS_gegraveerd.stl` | Eén kleur, verdiepte letters |
| `makita_clip_initialen.scad` | Parametrisch OpenSCAD-bestand (initialen/lettergrootte/mode aanpasbaar) |
| `button_cc0.stl` | Basismodel: "makita battery button" van Илья, Printables 1741157, CC0/Public Domain |

## Printen

- Materiaal: PETG (of ABS) — PLA is te bros voor dit klikdeel
- 6 wanden / hoge infill, laaghoogte 0.12–0.16 mm voor nette letters
- Pas de print eerst naast de oude clip voordat je hem monteert (breedte model: 36,8 mm)
